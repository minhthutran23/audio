1Kết nối GitHub

🔒 Về token GitHub (bấm để xem)

Token chỉ dùng trong trình duyệt của bạn để gọi GitHub, không gửi đi đâu khác, không được lưu lại. Tạo Fine-grained token (Settings → Developer settings → Personal access tokens), giới hạn cho đúng 1 repo, bật 3 quyền: Contents, Actions, Workflows đều để Read and write.
